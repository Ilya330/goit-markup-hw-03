# goit-markup-hw-03

Домашнє завдання №3: геометрія, відступи та Flexbox для сторінки WebStudio.

## Перегляд

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```sh
python3 -m http.server 8000
```

Після запуску відкрийте http://localhost:8000. Для Google Fonts і modern-normalize потрібне інтернет-з’єднання.

## Структура

- `index.html` — семантична розмітка сторінки.
- `css/main.css` — імпорти загальних стилів і стилів секцій.
- `css/common.css` — базові стилі, `.container`, `.section` та `.sr-only`.
- `css/header.css`, `hero.css`, `features.css`, `team.css`, `portfolio.css`, `footer.css` — стилі частин сторінки.
- `images/` — зображення та наявні ресурси проєкту.

Контейнер має максимальну ширину 1158px із горизонтальними відступами 15px. Секції мають вертикальні відступи 120px; Hero — 188px за макетом. Features і Team містять по чотири картки в ряд, Portfolio — по три.
